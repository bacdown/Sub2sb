Sub2sb 2.0

订阅转换

将 Clash / YAML / 订阅内容转换为 sing-box 配置，支持多订阅合并、节点筛选和高级规则。

来源
添加订阅链接、上传文件或直接粘贴配置。
支持多个来源；转换接口沿用现有 /api。
可多次选择，内容会合并提交；总大小不超过 2 MiB。

支持的来源

  • HTTP / HTTPS 订阅 URL
  • YAML / TXT / JSON 文件
  • Base64 订阅内容
  • Sub URL
仅随请求发送，不写入 localStorage。
转换方案
选择适合客户端或路由器的基础模板。
节点处理
只保留你需要的节点，避免生成无用配置。
证书验证
按节点类型分别设置证书策略；未单独设置的类型使用默认策略。
高级配置
DNS、分流组、规则集、证书和出站配置按需展开。
