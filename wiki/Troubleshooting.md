# 常见问题

## 显示“没有解析到节点”

请依次检查：

1. 输入是否为 Clash/Mihomo 订阅内容或支持的代理 URI，而非登录页、HTML 页面或错误提示。
2. Clash YAML 是否包含根级 `proxies` 列表。
3. 节点类型是否受支持，且必需字段（如 `server`、端口、UUID、密码等）齐全。
4. URI 是否完整；通常订阅链接应使用服务商提供的订阅地址，而不是管理页面链接。

不支持的节点会被跳过；全部节点均被跳过时，转换会失败。支持范围请查看[支持的格式和协议](./Supported-Formats.md)。

## 下载订阅失败或内容无法识别

远程响应不是可识别内容时，CLI 会报告响应的 `Content-Type` 和字节数，不会输出响应正文或链接凭据。确认订阅服务返回文本而不是 HTML、登录页面或空响应。也可以在服务商处导出文件，下载后作为本地文件转换。

网页/API 远程下载只允许公网 HTTP(S) 地址，并会检查重定向目标。检查失败时，请确认域名可解析且链接不是指向内网的地址。

## CLI 提示必须指定模板

非交互命令行需要 `-c/--config` 参数：

```sh
python3 sub2singbox.py ./subscription.yaml \
  -c templates/config_phone.json
```

如果不想传参数，请在交互式终端运行 `python3 sub2singbox.py --interactive`。

## 自定义模板被拒绝

确认 JSON 可解析、根节点为对象，并且包含数组类型的 `outbounds`；数组中的每一项都必须是对象。API 请求中不能同时传 `template` 和 `template_json`。

上述检查不等同于完整 sing-box schema 校验。若配置通过转换但客户端无法加载，请按目标 sing-box 版本检查模板字段和策略组引用。

## API 返回 401

如果服务器设置了 `YAML2SB_API_KEY`，请求必须使用对应密钥：

```sh
curl -H 'Authorization: Bearer <密钥>' \
  https://<项目名>.vercel.app/api
```

也可以使用 `X-API-Key: <密钥>`。确认本地进程或部署环境中的变量值正确；更改 Vercel 环境变量后需重新部署。

## 输出文件位置不符合预期

`-o/--output` 可以明确指定路径。未指定时，CLI 使用第一个本地输入文件所在目录；全部输入都是远程链接时，使用当前工作目录。模板名会影响默认文件名。

## 配置导入后无法启动

转换只负责把受支持的节点并入模板，不保证模板及节点字段适配所有 sing-box 版本。请检查目标版本的配置 schema、入站端口占用、策略组 tag 引用和设备网络环境；不要将转换成功视为配置已验证。
