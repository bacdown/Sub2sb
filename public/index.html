Sub2sb

订阅转换

将 Clash / YAML / 订阅内容转换为 sing-box 配置，支持多订阅合并、节点筛选和高级规则。

来源
添加订阅链接、上传文件或直接粘贴配置。
支持多个来源；转换接口沿用现有 /api。
可多次选择，内容会合并提交；总大小不超过 2 MiB。

支持的来源

  • HTTP / HTTPS 订阅 URL
  • YAML / TXT / JSON 文件
  • Base64 订阅内容
  • Sub URL
仅随请求发送，不写入 localStorage。
