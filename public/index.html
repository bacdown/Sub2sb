bacdown

默认配置文件均支持 sing-box 1.14.x。

支持粘贴多条订阅链接，每行一个；服务端会逐条下载订阅内容，只允许访问公网 HTTP / HTTPS 地址，且每条下载上限为 2 MiB。

尚未添加文件。可分多次选择 YAML / TXT 文件，内容会合并提交；总大小上限为 2 MiB。

最小要求：JSON 根节点为对象，且包含数组类型的 outbounds；数组项须为对象。

保存和管理订阅短链接必须先在服务端设置 YAML2SB_API_KEY，并在此填写；普通转换仅在服务端启用了密钥时需要填写。密钥只随本次请求发送，不会保存在浏览器中。

证书验证

以所选内置配置为底稿。未开放的配置项保持原样；DNS、分流组和规则集的未选择项会从配置中移除。

DNS

分别在国内和国际 DNS 下拉框中多选要保留的服务器，每类最多选择两项。模板所需的本地、Hosts 和 FakeIP DNS 会保留在配置中，不在此处显示。

国内 DNS

点击 DNS 项即可选中或取消，每类最多选择两项。

点击 DNS 项即可选中或取消，每类最多选择两项。
